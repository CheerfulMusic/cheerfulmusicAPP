# 创作流程与DIY封面

2026-11-03。本轮修改针对PC网页与手机网页；仅本地实现和验收，未部署，未发起真实付费音乐、歌词或图片生成。

## 用户流程

`写故事 → 修改歌词 → 生成与试听 → 制作音乐礼物 → 分享`

1. 歌曲完成后停留在试听阶段。主要区域提供播放、调整歌曲、重新谱曲、更换封面和下载。只有用户选择“满意了，制作礼物”才打开礼物制作区，创建链接后才进入分享阶段。
2. “调整歌曲”可修改风格和男女声，再应用设置。应用本身不调用模型；重新谱曲由用户单独发起，使用一次歌曲请求额度。旧音频保留，可在“对比歌曲版本”切换试听。当前实现是重新生成完整编曲，不是精确修改原歌曲某几秒。
3. 歌词页可返回修改故事，原内容会保存；故事页提供“返回歌词编辑”，不需要再次调用模型。调整风格后可以复用已有歌词，生成时仅按当前作品版本保存、确认一份歌词快照。
4. 歌词语言新增`mixed`。DeepSeek默认中文主歌搭配英文副歌或短句，用户可补充段落安排；完整混合文本原样交给音乐模型，不进行自动逐句翻译。
5. 首页、试听页、底部播放器、作品列表及收礼页的播放/暂停统一为SVG。换封面仅更新播放器展示，不重新加载音频或重置进度。

## 等待与撤销

- 桌面为黑胶唱片与声波弹窗，手机为底部面板；展示真实阶段、已等待时间和封面，支持收起后继续处理，不显示虚构百分比。
- 新音乐任务的`next_attempt_at`为创建时间后5秒，worker不得提前提交。等待阶段提供撤销按钮。
- 后端原子执行`QUEUED → CANCELLED`，并在同一个额度准入锁下释放对应MUSIC预留。撤销与worker的`QUEUED → SUBMITTING`竞争，只有其中一个能成功。
- 已经开始提交、运行或提交结果未知时拒绝撤销，不承诺停止供应商任务或退款。关闭弹窗只收起界面。
- 撤销接口幂等；同一个请求键重放返回已撤销任务，不创建第二个付费任务。

## 封面上传与使用

- 用户可上传JPG、PNG或浏览器可读取的WebP照片，前端支持方形裁剪、缩放和水平/垂直位置调整。源照片最大10MB、1600万像素。
- 裁剪后以JPEG上传；后端独立验证实际图片格式、5MB大小与1600万像素上限，重编码为1024×1024 JPEG，去除原文件名和元数据，不接收SVG。
- 上传图片与AI图片是独立资产，可切换和恢复默认封面。选中封面采用乐观版本校验，避免另一页面修改被覆盖。
- 封面同步到作品试听、当前播放器、我的音乐及礼物页。封面和音频共用创建者存储容量，图片存储位于本地音频目录的同级`covers`目录，或私有OSS对象。
- 分享快照记录封面ID。更换当前封面不会改变已创建的链接；撤销或过期同时关闭公开图片访问。页面切换歌曲或封面后清除旧链接展示，避免误认为旧链接已经更新。
- 生成音频分享必须使用那首歌的原始歌词版本；调整故事或风格后，旧歌曲仍可按原歌词创建礼物，不允许拿另一版歌词误配该音频。

## KIE图片编辑接入

使用官方[Google Nano Banana Edit](https://docs.kie.ai/market/google/nano-banana-edit)模型`google/nano-banana-edit`。

用户主动点击“AI加工这张照片”才创建编辑任务。worker通过[Base64上传接口](https://docs.kie.ai/file-upload-api/upload-file-base-64)上传已校验JPEG，再向统一`createTask`提交一次图片编辑请求；通过`recordInfo`查询，校验任务编号、模型和HTTPS结果地址后下载归档。图片下载复用现有的地址登记、内部地址拒绝和重定向校验。

原图片保留；AI完成后显示候选图片，由用户选择是否应用，不自动覆盖封面。编辑任务、租约、外部任务编号、模型、来源图片和创作要求持久化。付费POST不自动重试；提交结果未知进入待核对，查询与归档可以恢复。

配置示例（密钥仅放实际私有配置或环境变量，不提交Git）：

```properties
qingfeng.cover.ai.enabled=true
qingfeng.cover.ai.scheduler-enabled=true
# 可选：独立图片密钥；不配置时复用KIE音乐密钥。
# qingfeng.providers.kie.image-api-key=...
# 可选：不配置时为音频目录同级的covers目录。
qingfeng.cover.directory=./data/covers
qingfeng.oss.cover-prefix=qingfeng/covers/
qingfeng.usage.cover.daily-per-creator=5
qingfeng.usage.cover.daily-global=20
qingfeng.usage.cover.concurrent-per-creator=1
qingfeng.usage.cover.concurrent-global=2
```

封面额度独立于音乐每天20次额度。当前密钥仍需具备该图片模型权限及可用额度，本轮未验证真实权限、扣费或出图质量。普通上传、裁剪和封面应用不调用图片模型。
