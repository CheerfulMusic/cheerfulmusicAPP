# 全站浅色品牌风格

2026-11-04，将单页灵感入口的浅粉白背景、深色正文和橙红操作扩展到现有网页页面，保留业务流程。

覆盖首页、灵感输入、歌词编辑、生成与试听、作品列表、找回页、收礼页和未找到页面，以及音乐设置、生成等待、局部改词、封面编辑、分享入口、播放器及手机导航。

## 实现

- `brand-theme.css` 统一背景、表面、边框、文字、主操作、成功、警告、错误和焦点色。
- 将已加载样式中的深色固定颜色改为语义变量，继续保留各页面原有布局和响应式规则。未对封面照片使用颜色反转或滤镜。
- 更新共享导航的品牌符号、浅色菜单、页脚、表单、悬浮操作栏和原生弹窗。
- 原生弹窗使用柔和的遮罩；播放器保留播放、重试、进度拖动和关闭逻辑，仅调整视觉。
- 默认歌曲封面新增中英文浅色 SVG，使用新路径避免复用旧封面缓存；旧默认封面地址仍参与语言兼容。自定义封面不改动。
- 浏览器 `theme-color` 和 `color-scheme` 同步为浅色，避免手机浏览器边框或原生控件沿用深色。

## 验证与限制

- 70 项前端测试通过，包括更新后的默认封面语言切换检查；类型检查和生产构建通过。
- 140 项真实无头 Chrome 检查覆盖中英文、1440 与390视口、各页面和上述弹窗；检查无横向溢出、浅色原生控件及可见区域无残留深色 UI 表面，封面图片和媒体控件的合理对比层除外。
- 单页灵感入口另外完成50项回归检查，包括五种视口、保存恢复、语言选择、旧草稿兼容以及歌词可修改。
- 浏览器业务接口使用隔离模拟；播放器检查使用项目现有示例音频。不提交真实音乐、歌词、封面加工或分享请求，不代表付费生成或真机验收。

构建输出为 `.cache/all-light-dist`，未覆盖默认发布包。截图在 `outputs/all-pages-light/`。本轮仅前端视觉修改，未部署、未重启用户服务。
