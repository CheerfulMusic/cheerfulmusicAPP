# 共享开发数据库

> ⚠️ **历史文档（2026-11-07 标注，已废止）**：项目已统一使用 cheerfulmusic.com 线上生产主库 `qingfeng_music`，不再建立独立开发库或支付专库。现行约定见项目根 `AGENTS.md`「日常数据库使用」与 `docs/主库日常运行.md`；取代关系见 [ARCHIVE](ARCHIVE.md)。

2026-11-05已在服务器47.84.5.172创建独立库 `qingfeng_music_dev`。生产库为 `qingfeng_music`，同一MySQL实例无法创建两个同名库，因此开发库使用后缀，不覆盖生产数据。

源库是本机 `127.0.0.1:3306/qingfeng_music`，使用single-transaction导出表结构与全部数据，导入后23张表逐表计数一致，共531行，Flyway版本V14。本机源库未改动。之后两库独立，不会自动双向同步。

数据库用户 `qfdev` 仅有开发库权限，无生产库权限、无授权其他用户权限。SSH用户 `qfdev_tunnel` 仅允许转发到127.0.0.1:3306，不允许命令执行、TTY或代理转发。两种密码单独交付，不写入本文或Git。

## 数据库客户端

在DataGrip / DBeaver / IDEA Database配置：

| 区域 | 配置 |
| --- | --- |
| SSH主机/端口 | 47.84.5.172 / 22 |
| SSH用户 | qfdev_tunnel，密码认证 |
| MySQL主机/端口 | 127.0.0.1 / 3306，指SSH服务器侧地址 |
| 数据库 | qingfeng_music_dev |
| MySQL用户 | qfdev |

SSH认证用隧道密码，MySQL认证用数据库密码；这不是同一个账号。不要直接连接公网3306，服务器仍只监听本机。

## 本地运行后端

先在独立终端运行并保持该窗口：

```powershell
ssh -N -L 13306:127.0.0.1:3306 qfdev_tunnel@47.84.5.172
```

配置本机私有文件，不提交Git：

```properties
spring.datasource.url=jdbc:mysql://127.0.0.1:13306/qingfeng_music_dev?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai
spring.datasource.username=qfdev
spring.datasource.password=单独提供的数据库密码
```

使用的SSH隧道密码在ssh命令提示时输入。不要把公网IP写进JDBC的3306地址。

## 协作边界

- 开发成员共享同一套表和数据。Flyway迁移需要团队使用一致源码，由约定的一个服务先执行；不要各自修改已执行的迁移文件。
- 多个本地后端会竞争同一批后台模型任务。建议约定一个开发后端处理后台任务，其余实例关闭 `qingfeng.generation.scheduler-enabled` 和 `qingfeng.cover.ai.scheduler-enabled`；需要暂停实际音乐执行时还应关闭 `qingfeng.generation.enabled`。
- 数据库里的音频和封面记录只保存文件引用，复制数据库不等于复制所有本地媒体文件。团队若要共同使用这些文件，需要统一OSS或共享开发后端，不能让各台电脑分别使用不一致的本地文件目录。
- 本机私有配置未自动改为共享库。数据库密码权限只限开发库，但它允许改表和删除开发数据，团队不要对共享库运行清空库或重建库脚本。
