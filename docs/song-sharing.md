# 歌曲卡片与音乐海报

歌曲结果页的“分享歌曲”打开统一分享面板：歌曲封面、歌曲名称、试听、系统分享、海报和备用公开链接。

## 访问和展示

- 继续使用已确认歌词与选定音频创建的 `/gift/{token}` 快照链接，默认有效期 7 天。
- 系统分享传递标题、简介与公开链接；接收应用决定卡片样式，不承诺聊天消息内原生播放。
- Spring 的公开收听页首次 HTML 响应包含 Open Graph / Twitter 标题、封面及地址；Vue 脚本与页面挂载点保留。
- 部署域名默认 `https://cheerfulmusic.com`，可通过 `qingfeng.sharing.public-base-url` 设置 HTTPS 站点根地址；不使用请求中的 Host / Forwarded 头拼接预览地址。
- 代理层应将 `/gift/*` 请求交给后端，不能用静态 SPA fallback 提前截断。现有 nginx 全站代理配置符合此要求。
- `/brand/share-default-cover.png` 是不需要邀请码的公开品牌图片，不包含用户内容。用户封面仍必须通过有效分享令牌读取。
- `/api/public/gifts/{token}/cover?proxy=true` 返回授权后的同源封面内容，供画布制图和卡片预览使用；普通封面请求继续沿用现有 CDN 策略。

## 海报

- 浏览器本地绘制 1080×1800 PNG，不调用图片模型，不向第三方二维码服务发送分享令牌或歌词。
- 使用本次分享的歌曲标题、封面和已公开歌词；可选一句歌词、填写海报署名或不展示歌词。署名仅出现在本次海报，不修改账号与作品。
- 修改选项后需重新生成预览；过期异步制图结果会丢弃，关闭或切换作品时释放图片 URL。
- 支持下载、长按保存，以及浏览器支持时的系统图片分享。不支持系统分享时提供复制链接或保存图片。
- 二维码沿用快照链接的有效期，海报上显示到期时间。撤销分享会使链接与二维码失效，但不能收回已经保存的图片或音频。
- 本机和内网地址会明确提示可达性要求，不会将本地令牌擅自改成线上域名。

## 验证与发布

- 分享、海报状态与系统分享取消/失败降级：前端测试及浏览器检查。
- HTML 元数据转义、快照隐私、撤销失效、CDN 代理封面及邀请码启用后的匿名访问：后端测试。
- 无新增数据库迁移，不调整生成模型与支付配置。本次开发未部署；外部应用实际卡片展示需上线后分别验收。
