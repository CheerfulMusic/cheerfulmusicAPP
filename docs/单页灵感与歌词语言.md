# 单页灵感与歌词语言

2026-11-04，用户确认将创作入口简化为单页自由灵感输入，主按钮为“生成歌词”，先展示歌词供修改，再生成音乐。

- 移除收歌人、送歌时刻、回忆、心意和单独的语言选择屏。
- 单个文本框支持故事、情绪、场景或主题，最多4000字符；右下角选择中文、英文或中英混合。
- 灵感方向标签只改变输入提示，不替用户编造或覆盖经历。
- 保留自动保存、本机副本、冲突处理、版本控制、离开保护及歌词请求幂等标识。
- 旧问题参数统一回到单页；旧作品的收歌人、时刻、心意保留在可展开的信息区，不清空数据库历史字段。
- 新作品允许空收歌人、空时刻，不填入虚构默认值。后端仍检查空请求、字段非空值和长度、身份及版本。数据库结构无需迁移。
- 无收歌人的作品在歌词页、作品列表和歌曲结果处使用原创作品文案，不显示空白收歌人。

验证：70 项前端测试通过；7 项 WorkPersistenceIntegrationTest 通过，包含真实 HTTP、安全链、H2 与 MyBatis 的自由灵感保存、更新和身份隔离；4 项 DeepSeekLyricsFlowTest 通过，使用离线写词器验证无收歌人的灵感、中英混合和幂等请求，未调用真实模型。

50 项隔离浏览器检查通过，覆盖五种屏幕宽度、中英文、输入框右下角语言选择、必填校验、标签不覆盖输入、模拟自动保存、刷新恢复、提交一次歌词请求、歌词可编辑及旧链接兼容。浏览器接口为模拟，不等同于真实付费模型验收。

构建输出为独立的 `.cache/inspiration-entry-dist`，截图在 `outputs/single-inspiration-implemented/`。未部署。由于后端必填校验有变，本地体验需重启 IDEA 中的后端后再刷新页面。
