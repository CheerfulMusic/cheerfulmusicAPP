# 第二屏试听作品与新封面

日期：2026-11-04。本轮本地实现，未部署。

第二屏采用确认版式：标题“听听这些歌，你也能创作。”，英文“Discover What You Can Create.”；副标题采用用户给出的中英文原文。中文界面中英同屏，英文界面仅英文。卡片保留“试听”和“用这个风格创作”，下方保留统一创作按钮。手机卡片横向滚动，切换分类后回到起始位置。

用户在风格确认中回复“就是爱情、家庭、自由旅游”，因此当前三首真实音频继续按这三个主题展示，没有根据封面把录音擅自标成电子或民谣。“更多风格”提供8个创作入口：抒情流行、梦幻电子、独立摇滚、温暖民谣、R&B、说唱嘻哈、轻柔爵士、国风古韵。它们用于创作偏好，不冒充已有对应风格的试听录音。后续补充已确认风格的音频后再扩展试听分类。

“用这个风格创作”传递当前曲目的原有主题偏好；“更多风格”传递选中的音乐风格。新草稿读取白名单内的偏好，未知参数回退为默认值；已有作品和恢复副本按原有流程处理。进入创作不会自动请求歌词或歌曲模型。
