## 2. 交付范围

### 首个验收版本：完整Web/H5音乐礼物闭环

用户从已确认风格的首页进入，填写故事，生成与修改歌词，确认指定版本，真实提交音乐生成任务，查看并恢复进度，试听与下载音频，在自己的作品中找到成果，主动分享给无需登录的收礼人，且可撤销分享。

电脑网页与手机网页共用Vue业务模块；全站播放器统一管理。首版采用可信匿名创建者会话，后端保证作品归属；同一浏览器可找回作品，不承诺匿名用户跨设备同步或清理会话后自动恢复。

### App交付阶段：独立安装与原生差异验证

基于相同Vue代码和Java接口生成Android/iOS原生工程，处理安全区、系统返回、生命周期、HTTPS API、身份持久化、分享和文件保存。生成中断前台不影响后端任务，恢复前台时重新查询。

Android需可用SDK/JDK工具链和测试设备；iOS需Apple构建环境、签名与设备。缺失工具链时可继续网页和公共业务工作，但不能将App标记为交付完成。后台/锁屏播放单独验收，Web音频播放不算原生后台播放完成。

### 暂不纳入首版

支付、会员、额度套餐销售、声线克隆、AI封面生成、歌词视频、逐字卡拉OK、复杂运营后台、微服务和自动上架应用商店。开发过程中不自行扩大这些范围；需要时单独排期。保留架构扩展点。

## 3. 优先级和完成定义

- P0：首个真实业务闭环和基本安全可靠性必须完成。
- P1：首版体验、交付质量或App阶段必须完成。
- P2：得到明确需求后再开发。
- 一项任务只有代码/配置已完成、相应验证有结果、依赖已说明才标记完成。目录、假数据、接口返回固定成功不算业务完成。
- 模拟供应商仅用于自动化测试，运行界面和验收结果必须明确区别于真实生成。

## 5. 执行顺序和检查点

```text
用户确认计划
  → 核实资源、最小真实生成验证
  → 接口与数据设计
  → 身份、作品草稿、正式UI迁移
  → 歌词生成与版本确认
  → 音乐任务、音频归档、恢复
  → 结果、作品、分享与播放体验
  → 测试、Web/H5部署与验收
  → 原生App适配、打包和真机验证
  → 分平台交付清单
```

- 检查点A：正式首页已迁入Vue，草稿能够真实保存且不能越权。
- 检查点B：用户确认的歌词真实生成歌曲，刷新和后端重启可以恢复进度。
- 检查点C：可播放、下载、管理作品和分享/撤销；Web/H5在线验收。
- 检查点D：各目标App安装和核心功能真机验证，不把Capacitor配置文件当完成。

每完成一组任务，提供已完成编号、验证证据、可体验入口、问题和下一组任务。确认整体计划后，在已确认范围内持续推进；只有业务范围改变、缺失必要资源或存在外部付费/发布决策需要补充时再提出问题。不会每完成一个函数就再次要求确认。
