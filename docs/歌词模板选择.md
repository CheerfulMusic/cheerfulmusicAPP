# 歌词模板选择（本地实现，2026-11-06）

本次只增加歌词结构选择相关代码，未部署，未调用真实付费模型。其他并行页面改动未合并或重置。

## 使用

在创作灵感输入框右上角点击“歌词模板”按钮；歌词编辑页的“调整并重新生成”区域也有相同按钮。电脑端打开居中弹窗，手机端打开底部弹层。弹窗中点选只更新预览，点击“确认选择”才应用；取消、关闭或 Esc 保留原设置。默认“自由结构”，可选AAB、ABB、ABC、ABCD，旁边可单独开启“副歌先行”。自由结构下先选定一个模板，再开启副歌先行。

- AAB：Verse 1 → Verse 2 → Chorus → Interlude → Verse 2 → Chorus → Chorus 2
- ABB：Verse → Chorus → Chorus 2 → Interlude → Verse → Chorus → Chorus 2
- ABC：Verse → Pre-Chorus → Chorus → Interlude → Pre-Chorus → Chorus → Chorus 2
- ABCD：Verse → Pre-Chorus → Chorus → Interlude → Pre-Chorus → Chorus → Bridge → Chorus

副歌先行将第一个Chorus移动到开头，从原位置删除，并非再复制一个副歌。Interlude为纯器乐间奏标签，Chorus 2为第二副歌，不替换成Bridge。模板仅约束段落顺序，不固定旋律或歌词内容。

## 链路与兼容

前端提交独立字段templateId、chorusFirst；后端LyricsStructure校验枚举并构造完整段落约束，经原有LyricsWriter传到DeepSeek的revisionInstructions。新结构也参与后端请求指纹和前端首次生成请求键，避免误用旧模板的成功结果。旧客户端缺省字段仍使用AUTO，原有幂等指纹保持兼容。

生成后在登记新版本前验证段落标签、顺序、非空歌词及间奏为空。未符合模板时记录本次失败，不插入歌词版本，不自动重试付费请求，已有版本不变。失败并不代表供应商不计费。中文、英文、中英混合共用结构约束，语言选项继续独立生效。

选择跟随本机草稿恢复与首次生成跳转参数保留；不是新建数据库模板字段。尚未增加跨设备模板偏好同步。切换选择本身不请求生成或创建歌词版本。
