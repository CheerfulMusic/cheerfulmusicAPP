# 手机号绑定与50积分奖励

在“我的资料 / 账号与安全”增加短信绑定入口，仅已登录的音乐账号可操作。手机号须含国家区号，沿用现有短信地区开关、限流、六位验证码、十分钟有效期和五次尝试限制。

短信提供方完成验证后，将手机号的登录身份关联到当前创作者；其他账号已经占用的手机号不能绑定。原作品和会话归属不变。绑定与50积分流水在同一事务中提交，流水引用为 `phone-binding:<creator>`，账号只能领取一次，不支持换绑或解绑。此前已用手机号登录的账号不补发此奖励。
