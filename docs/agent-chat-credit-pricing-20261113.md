# Agent 精确改词与超额对话积分

## 行为

- 明确要求将第一句或最后一句替换为给定文字：在当前会话、作品、歌词版本核对后精确保存，保留其他文本、换行及标点，不调用规划或写词模型，不收对话积分。已有音频不自动改变。
- 每日个人免费预算保持现有配置；额度是保守的 token **预留预算**，不能当作供应商实际 token 用量展示。
- 个人免费预算不足后，每轮 1 积分。前端先显示服务端价格说明、确认后才提交付费授权；写词、音乐等独立工具仍按原价计费。
- 全站预算、并发、频率限制不因付费被绕过。明确本地改词无需模型 token，但仍受频率、并发和所有权保护。
- 积分流水引用为 `agent-chat:<admission id>`；授权、扣费和准入记录处于同一数据库事务，重复请求不重复扣费。积分不足不创建准入记录、不执行工具。
- 进入执行器前被拒绝（包括 Redis 准入失败）退回积分；退款请求置为 ABANDONED，禁止旧幂等键免费重执行。进入执行后的不确定结果保留原请求及扣费，供核对，不自动重发或假定外部动作失败。
- 仅增加应用逻辑，复用现有准入与账本表；无新增数据库迁移。

## 价格依据（2026-11-13）

官方价格来源：https://api-docs.deepseek.com/quick_start/pricing/

当前默认规划模型为 `deepseek-flash`。按峰值、输入全部缓存未命中计：输入 $0.30 / 百万 token，输出 $1.20 / 百万 token。每轮最多两次规划，每次输入预算 65,536 bytes（用每 byte 至多一 token 作保守估计）、输出最多 2,600 token：

`2 × (65,536 × 0.30 + 2,600 × 1.20) / 1,000,000 = $0.0455616`

仓库套餐默认价为 $9.90/100、$25.90/300、$49.90/700 积分，每积分约 $0.0713–$0.099。每轮 1 积分在上述最坏规划成本下保留约 36%–54% 的模型成本毛差，用于支付手续费与应用运行成本；这不是净利润估计。普通短对话的实际 token 成本通常低于上限，但现有积分为整数，故采用预先告知的按轮定价，不声称按实际 token 精确结算。

供应商变价、模型替换、提高上下文上限、套餐折扣或赠送积分都会改变测算，需重新核算。未查询私有账户折扣或真实供应商账单。本次不调整免费预算，不变更生成歌词/音乐价格。

## 验证与生效

验证使用 H2、模拟供应商及本地前端测试，未连接主库、未执行真实扣费。完成开发后合入本地 main；上线和本地运行实例切换须另行明确执行，代码合并不代表运行环境生效。

验证结果：前端 94 个文件、749 项测试通过，TypeScript/Vite 构建通过。后端已运行集合累计 1197 项通过、72 项条件测试跳过；完成现有环境可运行的 verify 后，对最终改词边界、HTTP 兼容及扣费事务另做针对回归，均通过。并发相同请求只扣一次、准入入库失败时扣费回滚、执行器拒绝退款、旧请求重放及积分不足均有测试。

无参数 `mvn verify` 发现 6 组已有支付测试需要未配置的专用隔离 MySQL：CreditEntitlementV40MySqlMigrationTest、CreditHistoricalCutoverMySqlTest、DisputeOverlapMySqlTest、IntegratedCreditAccountMySqlTest、IntegratedPaymentApplicationMySqlTest、LegacyCore40ApplicationMySqlTest。随后仅排除上述 6 组重跑可运行集合；这不代表完整支付／真实 MySQL／资金验收通过。
