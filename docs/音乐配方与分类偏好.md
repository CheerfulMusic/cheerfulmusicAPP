# 音乐配方与分类偏好

2026-11-03，本地实现方案二，未部署，未进行真实付费生成。

## 用户流程

歌词页点击「选择旋律与声音」，或歌曲结果页点击「调整歌曲」，打开音乐选择面板。默认提供温暖诉说、甜蜜轻快、深情告白、复古律动、热血鼓励五种可编辑配方。配方仅为偏好组合，不关联固定旋律或音轨。

可展开精细调整：主风格与融合风格最多2项、演唱方式最多2项、音色最多1项、情绪最多2项、乐器最多3项、速度最多1项。主风格和主乐器由选择顺序决定，界面标注「主」。声音偏好独立选择自动、男声、女声。律动与编曲放在高级选项中。

排除项提供标签和200字自由输入，补充要求上限300字。配方切换保留自行编写的要求、排除项及声音；从旧版导入的原风格描述只在明确改选新配方时替换。声音、速度及说唱等明确冲突会提示并阻止确认。伤感和「不要太悲伤」属于程度偏好，允许同时选择。

摘要由后端确定性整理，无需额外调用大模型。选择项不足或冲突、描述超出供应商长度时不能保存，不静默截断。保存偏好不开始生成；用户再明确点击生成歌曲。

补充要求影响之后的音乐生成，不自动改写现有歌词。歌词润色继续在歌词编辑区明确执行并保留版本。没有经过确认的授权试听素材时不展示配方试听入口，避免把无关样曲冒充目标风格。

电脑使用左右分栏弹窗，选择区域和摘要并列，摘要随滚动保留；手机使用全屏面板，已选标签顶部固定、底部确认。所有标签使用稳定编号，中英文只改变展示文案，不翻译用户自行写的内容。

## 数据与模块

- `qf-business/.../settings`：偏好模型、规则校验、描述整理和应用服务。
- `qf-infrastructure/.../resources/music/catalog-v1.json`：唯一标签及配方目录，包含中英文名称和生成映射。同一目录版本不应随意删除或改变已有编号含义。
- `JdbcMusicSettingsRepository`：当前设置和不可变任务快照。
- `MusicSettingsController`：读取目录、预览、保存及查询生成历史设置。
- 前端 `MusicSettingsPanel`、`music-preferences`：选择交互、目录驱动渲染、本机编辑恢复；`MusicSettingsSnapshot` 展示当前音频所属任务的设置。

Flyway V13新增 `work_music_preferences` 与 `generation_music_preferences` 两张表，不删除或改写旧歌曲。原作品的80字 `style` 继续用作简短展示，完整偏好和生成描述独立保存，因此无须把长描述塞进原字段。

保存音乐设置使用作品版本号并递增，保留故事、祝福和标题。旧客户端若改了风格或声音，原结构化设置不再强行覆盖它；无偏好快照的旧任务继续使用原风格和声音。

生成时在同一事务中冻结分类偏好、目录版本、实际风格描述、排除项和中英文摘要。准入锁与作品锁使用一致顺序，版本变化时要求重新确认，避免跨页面更新混入另一次生成。

Worker读取任务快照提交，KIE的 `style` 使用已整理的描述，声音映射到 `vocal_gender`，排除项独立提交 `negative_tags`；不会再叠加旧24种风格展开造成默认乐器冲突。局部改词继承原曲任务快照，当前新配方不会改变原曲修订方向。模型对这些偏好的遵循程度仍需实际试听验收。

## 接口

均沿用会话、CSRF和作品归属校验；目录和预览也位于创建者接口下。

| 方法 | 路径（前缀 `/api/app`） | 行为 |
| --- | --- | --- |
| GET | `/music-settings/catalog` | 获取版本化目录 |
| POST | `/music-settings/preview` | 校验和整理，不保存、不占模型额度 |
| GET / PUT | `/works/{work}/music-settings` | 读取 / 带expectedVersion保存 |
| GET | `/works/{work}/generations/{task}/music-settings` | 获取本版生成快照，旧版无记录时为空 |

本机草稿按浏览器创建者与作品隔离。恢复前验证结构及标签编号；较旧作品版本的本机设置需用户明确恢复。保存失败保留编辑，保存成功清理本机草稿。
