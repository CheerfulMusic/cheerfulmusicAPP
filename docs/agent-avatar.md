# Agent 对话头像

用户可在 Agent 对话中设置头像。上传支持不超过 5 MB 的 JPG、PNG，服务器会验证图片、裁成正方形并重新编码；头像按当前创作者账号保存。

AI 头像使用 Kie 的文生图任务。用户在对话中描述头像并确认后提交，每张消耗 5 积分，完成后自动设置；如果用户在等待期间更换过头像，则保留较新的头像并退回积分。明确失败时退回积分；结果不确定时保留待核对状态，不会自动重复提交或退款。

## 启用条件

上传需要数据库迁移 `V38__creator_avatar.sql`；AI 生成还需要 `V39__avatar_generation_task.sql`。迁移和部署须按项目上线流程单独安排，不能在日常连接生产主库的本地入口执行未上线迁移。

AI 生成默认关闭。上线准备时，须先确认 Kie 文生图模型权限、实际费用、服务端密钥和积分计费配置。确认后通过受控运行环境配置以下选项：

```properties
qingfeng.avatar.ai.enabled=true
qingfeng.avatar.ai.scheduler-enabled=true
qingfeng.avatar.ai.daily-limit=3
```

每日上限按账号最近 24 小时计算，可配置为 1–100。密钥使用服务端既有的 Kie 图片 API 密钥配置，不写入仓库。生成与调度开关开启、积分服务及供应商密钥可用时，前端才显示生成可用；其他情况下仍可上传头像。

生成状态为 `UNKNOWN` 时，需要先用供应商记录核查任务和费用；不能通过自动重提绕过不确定状态。上线前应在隔离环境验证真实供应商权限、生成及重启恢复，再按项目流程检查数据库迁移、备份和回滚方案。
