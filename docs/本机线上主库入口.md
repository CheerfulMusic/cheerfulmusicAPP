# 本机连接线上主库

本机日常入口为 `scripts/start-main.ps1`，`scripts/start-local.ps1` 也转入该入口。停止使用 `scripts/stop-main.ps1`。

数据库通过 SSH 隧道从本机 `127.0.0.1:13306` 连接服务器 `127.0.0.1:3306/qingfeng_music`。不向公网开放数据库端口，不复制或清理原本机数据库。

2026-11-09 已核对线上版本 `e2422c5ff8539e1e1c1059790283a12817f96e59`，本机使用完整 SHA256 与线上一致的 JAR 和独立目录中的匹配前端。访问 `http://127.0.0.1:5173`，后端为 `http://127.0.0.1:8080`。

私有配置、版本清单位于被 Git 忽略的 `.secrets/`，运行材料位于 `.cache/runtime/production-main/`。SSH 私钥默认使用 `.cache/deploy-ssh/id_ed25519`，也可通过 `QF_SSH_KEY_PATH` 指定；主机指纹使用 `.cache/deploy-ssh/known_hosts` 严格校验。

本地禁用 Flyway、SQL 初始化、生成/封面后台调度和本地支付处理。后台任务由线上服务执行，前端业务请求按入口规则使用线上接口。不要通过自动化生成、模拟付款或测试夹具验证生产数据。

不要直接用旧 IDEA `MusicApplication` 源码配置代替这个入口。本地 main 含尚未上线的 V26 软删除迁移，而线上主库当前为 V25；关闭迁移并不能让这些未上线的表结构需求自动兼容。需要调试最新源码时应先制定兼容方案，不自动修改生产主库或执行 repair。

本次仅切换本地连接和运行入口，未部署或重启线上服务。旧连接配置已保存在忽略提交的 `.backups/main-connection-*/` 中。
