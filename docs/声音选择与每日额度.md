# 声音选择与每日额度

后续更新：当前测试期已取消每日次数上限，额度与并发统一使用独立配置文件。以下20次规则为当时的历史记录，现状见[统一创作额度配置](统一创作额度配置.md)。

2026-11-03，按用户要求新增演唱声音选择，并将个人音乐日限额由 3 次提高到 20 次。

## 声音选择

「制作一首歌 → 选择旋律」在音乐风格下增加「演唱声音」单选：自动选择 / 男声 / 女声。PC 和手机均显示三个可点击选项，支持键盘操作及中英界面。默认自动选择；旧作品与旧本机草稿缺少该字段时按自动处理。

声音偏好随草稿自动保存到数据库，本机恢复保留选择。生成时将该值写入独立任务快照，后续编辑作品不会改变已提交任务的声音选择；Worker 从任务快照读取，适配器发送 KIE 的 `input.vocal_gender`，男声 `m`、女声 `f`、自动不传此字段。风格提示不再混入「温柔女声」，以免和新的声音选项冲突。

根据 [KIE 官方生成音乐文档](https://docs.kie.ai/suno-api/generate-music)，该参数是声音偏好，仅在自定义模式生效，不保证模型每次严格遵循。当前项目使用自定义模式，界面亦提示以实际生成结果为准。

新增 Flyway V9，为 `music_work` 与 `generation_task` 增加 `vocal_gender`，旧记录默认 `AUTO`。API 接受 `AUTO / MALE / FEMALE`，非法值在访问供应商前拒绝。后端未升级而忽略新参数时，前端提示重启，不会把声音选择误显示为已保存。

## 每日额度

- 音乐：个人每天 20 次生成请求；全站每天合计仍为 20 次，多人共享。个人同时 1 个、全站同时 3 个任务的限制保留。
- 歌词：个人每天 20 次 AI 编写请求，全站 100 次；支持用户当天从故事开始连续制作 20 首新歌。
- 同步歌词：个人 10 次/天，全站 100 次，独立计数。

以上是应用内请求次数上限，不是 KIE 余额，也不是必定成功的歌曲数量。已准入失败请求仍保守计次，相同请求键重放不重复计次；不会清空当天已用记录。按上海时间每日重置。若其他用户已消耗全站名额，个人剩余次数仍可能受到全站限制。

已同时修改后端默认值、示例配置及本机私有配置；实际密钥保持原样。私有配置可覆盖默认值：

```properties
qingfeng.usage.music.daily-per-creator=20
qingfeng.usage.music.daily-global=20
qingfeng.usage.lyrics.daily-per-creator=20
qingfeng.usage.lyrics.daily-global=100
```
