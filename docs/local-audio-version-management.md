# 歌曲版本备注与删除：本地验证

每个版本支持最多 500 个字符的作者私有备注，可编辑、清空、保存；跨页面保存通过 noteVersion 检查冲突，不覆盖新备注。输入框与版本选择的 radio 独立，编辑不会切换音频。

删除需确认，只从版本列表逻辑移除，不物理清除音频，不退存储计量。现有分享、局部改词来源和生成审计仍能引用原音频。当前选用、公开发布的版本禁止直接删除；必须先切换选用、替换公开版或设为私密。至少保留一个可见版本，全部删除需使用删除作品。删除幂等，已删版本不能重新选择、修改备注或再次发布。选用、删除和发布通过音频行锁串行化；选用、备注和删除参加调用方事务。

版本编号根据包含已删除记录的完整生成音频历史计算，保持原先 created_at/id 排序；不会因为删除或超过列表的 100 条上限重排已有编号。

## 数据库准备边界

本次不调整主库、不修改日常启动配置，也不推进任何财务迁移。版本扩展表脚本位于 `Qingfeng_AI_Music/qf-infrastructure/src/main/resources/db/optional/audio_version_annotations.sql`，不属于自动 Flyway 升级链。未来发布本功能前须单独备份并在目标业务库执行此脚本，再部署代码；不能通过提高 Flyway target 绕过财务升级审批。脚本可重复执行，只创建 media_asset_annotation，不改既有音频数据。回退旧应用可保留此表。

仅 test 配置自动初始化扩展表；测试必须使用内存 H2 或指定隔离 MySQL。日常本地入口使用的固定 JAR、前端和主库均未更新，本地 main 合并不表示运行版本生效。
