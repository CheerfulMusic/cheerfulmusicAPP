# 旋律与声音入口强化

2026-11-04，针对歌词页“选择旋律与声音”入口不明显的问题，调整前端展示。

- 将歌词下方的小按钮替换为整块可点击的浅橙设置卡片，使用音乐图标、加粗标题、用途说明和箭头。
- 卡片展示作品当前的风格与人声偏好，读取已有作品字段，不写入默认值。
- 电脑端避免重复展示原小按钮；手机底部保留更明显的“旋律与声音”入口。
- 两个入口均沿用 `adjustMusic` 打开原音乐设置面板；生成中、提交结果核对中或保存设置时继续禁用，未改变生成流程。
- 已完成歌曲继续使用原有“调整歌曲”入口。支持中英文、键盘聚焦及减少动态效果偏好。

验证：70项前端测试、类型检查及构建通过。57项隔离浏览器检查通过，覆盖1440、1024、768、390、360视口和中英文、摘要、卡片及手机按钮打开设置、面板打开后隐藏手机操作栏、任务期间禁用、完成状态及无模型提交。

浏览器业务接口使用模拟；未调用付费模型，未部署。构建输出 `.cache/sound-entry-dist`，截图在 `outputs/sound-direction-entry/`。
