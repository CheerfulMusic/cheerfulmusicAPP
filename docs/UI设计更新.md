## 实现与检查

### 音乐生成进度弹窗（2026-11-02）

点击“生成歌曲”立即显示430px以内的原生dialog，沿用黑灰底与橙红品牌色，以唱片和音波动效呈现音乐创作。阶段由任务状态映射为提交、谱曲与演唱、保存，不提供估算百分比。完成后停止动效并可定位到音频区；失败及提交结果待核对状态给出独立说明，不自动重提。

可关闭并在后台继续；任务进行中或结果待核对时，作品页入口显示“查看生成进度”。进入有进行中任务的作品也会恢复弹窗。原生dialog负责焦点范围及模态交互，Escape与关闭按钮均仅关闭显示，页面减少动画设置会停用动效。

14项前端测试、类型检查及构建通过。浏览器验证1440/390/320视口、阶段切换、查询中断、成功定位、失败、未知提交、后台继续、重新查看、焦点恢复和英文文案；完整模拟流程仅一次生成POST，未请求真实付费模型。证据位于.cache/generation-dialog-qa.json及.cache/screenshots/generation-*.png。

### 创作示例标签（2026-11-02）

三步创作中的称呼、特别时刻和音乐风格统一使用SuggestionField组件：输入框下展示常用标签，可展开16个称呼、18个场景及24种风格。标签填入后仍可自由修改，选中采用品牌橙红描边与勾选提示。场景和风格的推荐值沿用原业务值，英文只翻译其显示；自定义内容原样保存。

12项前端测试、类型检查及构建通过。浏览器验证1440/390/320视口无横向溢出，标签点击不提交表单，自定义称呼／场景／风格真实保存并刷新恢复；切换英文保留自定义内容、推荐项提交值保持兼容。证据位于.cache/suggestion-tags-qa.json与.cache/screenshots/suggestions-*.png。未调用模型。

### 中英双语调整（2026-11-02）

首页标题改为“把你的故事，唱给重要的人。”。页头增加中／EN切换，公开礼物页也可直接切换；默认中文并保存本机语言偏好。保留Cheerful Music图形、品牌色及封面主体，英文使用相同风格并调整标题、按钮、页头和手机间距。

界面文案、内置试听示例、日期、操作确认、播放器提示与默认礼物封面提供双语。故事、姓名、用户歌曲名称、祝福和歌词保留输入原文，不调用翻译服务，也不随语言切换更改已保存内容。表单选项仅改变显示标签，提交值保持兼容；切换语言不会离开路由或重建表单。新增英文品牌封面为public/media/brand-cover-en.svg。

语言资源位于shared/i18n/en.ts；翻译、偏好、日期与封面选择由shared/i18n/index.ts统一处理，适配样式位于app/styles/i18n.css。

双语浏览器验收通过：首页覆盖1440/1024/890/768/390/320像素，页头无重叠、页面无横向溢出。验证刷新保留语言、播放中切换、未保存表单保留、英文界面真实保存草稿、中文原始内容恢复、歌词确认、音频导入、分享与礼物试听、找回码错误和无效链接提示。作品详情及收礼页覆盖1440/390/320像素。结果位于.cache/bilingual-qa.json，截图位于.cache/screenshots/bilingual-*.png。手机为Chrome模拟视口；测试未发起音乐模型调用。

### ToC体验调整（2026-11-02）

保留既定黑灰与橙红品牌色：#090A0C背景、#111318卡片、#191C22抬升层、#272B33边框、#F5F6F8文字、#FF3F27主要操作。使用原有系统无衬线字体，封面与歌曲名称承担视觉重点。

本次布局复核将常驻侧栏及工作台页头改为消费端顶部品牌导航：首页、送歌灵感、如何制作；右侧为我的音乐和送歌入口。手机使用紧凑菜单。移除全站运行状态提示与模拟头像，Logo保留图形和英文品牌，副标题改为青风音乐。首页优先展示情感场景与可试听封面，技术能力状态只在需要作出操作决定的页面说明。

```text
Logo        发现音乐 / 送歌灵感 / 如何制作      我的音乐 / 制作歌曲
送歌故事与主要操作                              专辑封面 / 试听
可试听的音乐灵感
送歌场景 / 三步制作 / 音乐礼物预览
```

此调整采用与参考图一致的品牌色，布局围绕个人用户“听一听、选场景、送一首歌”展开，避免把消费端主页设计成办公功能目录。未引入虚构用户数量、评价、已生成歌曲或登录状态。

ToC浏览器验收覆盖1440/1024/768/390/320视口：无横向溢出、手机菜单与Escape焦点、快捷场景、筛选试听、保存草稿、歌词确认、音频上传与礼物试听均通过。证据位于.cache/toc-theme-qa.json及.cache/screenshots/toc-*.png。顶部哈希导航为固定页头留出滚动距离，并尊重减少动画设置。

正式Vue入口改为theme-base.css及home.css，移除旧浅色样式的运行时导入；表单、作品、礼物等业务样式统一使用语义色变量。旧原型及其样式保留作历史参考。
