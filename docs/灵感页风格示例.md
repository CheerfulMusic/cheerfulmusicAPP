# 灵感页风格示例

创作输入框下方的标签改为：流行抒情、流行摇滚、蓝调R&B、华语民谣、中国风、我还没有灵感。

## 交互

- 点击标签会将对应的中文创作描述填入实际输入值，而不是只切换 placeholder；英文界面填入英文描述。
- 同时保存作品的风格和人声偏好。流行抒情为女声；流行摇滚、蓝调R&B、中国风为男声；华语民谣不强制人声性别。
- 文本仍可自由编辑、追加主题，按原有机制自动保存。切换界面语言不会翻译已经填写的内容。
- 提供一次“撤销填入”，恢复替换前的文本、风格和人声。用户继续修改了填入内容后，不再提供可能覆盖后续修改的撤销操作；原内容也会尝试保留到现有本机恢复副本。
- “我还没有灵感”填入开放式主题请求，并回到轻快流行、自动人声，不继承之前的摇滚或特定性别要求。
- 点击任何标签不调用歌词、改写或音乐生成模型。用户点击生成按钮后才进入对应流程。

## 提示词与任务

中文示例配置：`Qingfeng_AI_Music_VUE/src/modules/studio/model/inspiration-presets.ts`。

用户提供的五段完整英文编曲提示词集中在 `Qingfeng_AI_Music/qf-business/src/main/java/com/qingfeng/music/settings/InspirationMusicPresets.java`。它们不会作为歌词正文填入输入框。

保存草稿时使用风格名称及人声字段。读取音乐设置、预览及提交任务时，后端将名称解析为完整编曲描述；原有生成任务快照保存当时的英文描述和人声，之后修改作品设置不会改变已提交任务。

打开音乐设置后直接确认，不会把这五种预设降为泛化风格；更改人声会调整提示词中的性别描述，避免男女声要求冲突。用户更改分类标签后，按照新的选择整理编曲描述；排除项继续通过独立参数提交。

歌词作者提示词区分音乐制作要求和歌词素材，避免把“钢琴打底、男声演唱”等制作说明直接写成歌词。只有风格、没有主题时，可以创作不冒充用户私人经历的意象主题。

验证使用隔离 H2、模拟供应商与本地 HTTP；没有提交真实付费生成，也没有部署。
