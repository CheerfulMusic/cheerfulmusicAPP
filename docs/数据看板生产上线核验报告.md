## 5. 法务待确认事项（材料整理，供人工确认）

> 以下为**技术事实整理**，供法务/合规人工判定，**系统不自行声明合规**。

### 5.1 当前分析 Cookie 同意文案（前端 `AnalyticsConsentBanner.vue`）

> "我们使用匿名数据（仅页面路径、停留时长，绝不含歌词、邮箱或手机号）来了解网站使用情况以改进产品。这需要你的明确同意；拒绝不会影响你使用本站的任何功能。"

- 按钮：接受分析 / 拒绝；已接受态："已同意匿名分析" + 撤回；已拒绝态："已拒绝分析采集" + 更改。

### 5.2 接受 / 拒绝 / 撤回机制

- **接受**：`accept()` → `setAnalyticsEnabled(true)` → `qf.analytics.optout='0'` → 开始采集。
- **拒绝**：`reject()` → `setAnalyticsEnabled(false)` → `qf.analytics.optout='1'` → 停止采集；功能不受影响。
- **撤回**：`withdraw()` → 同拒绝路径 → `qf.analytics.optout='1'` → 停止采集。
- **更改**：`manage()` → 重新弹出选择（不改已持久化决定）。
- 默认态：未决定 = 不采集（绝不默认同意）。

### 5.3 采集的数据字段

**前端上报**（`track.ts` → `SiteEventController` 二次校验）：

| 字段 | 来源/处理 | 备注 |
|------|-----------|------|
| `event` | 白名单 10 种 | pageview/page_leave/gift_view/creation_start/lyrics_generated/song_generated/checkout_start/purchase/audio_play/gift_download |
| `page_path` | 仅 pathname，剥离 query/hash；`/gift/:token`、`/works/:id` 占位 | 不含 OAuth code / 礼物 token / 作品 id 原文 |
| `referrer` | 仅 scheme+host+path | 仅 http/https，剥离 query/hash |
| `visitor_id` | 匿名，1 年有效 | 见 5.4 |
| `session_id` | 匿名，30 分钟有效 | |
| `payload` | 仅 8 个白名单键：`route/durationMs/audioOrigin/provenance/provider/result/plan/status`；单值≤128 字符、≤12 键、总≤2048 字节 | |
| `creator_id` | **仅服务端**从 QF_SESSION 解析，前端传值无效 | 登录用户归属；未登录为空 |
| `duration_ms` | 来自 `page_leave` 的 `durationMs`，服务端限制 0..86_400_000（24h） | |

**明确不采集**：歌词内容、邮箱、手机号、OAuth 授权码、礼物 token 原文、作品 id 原文。

### 5.4 `visitor_id` 用途

- 匿名访客标识，存于 `localStorage`（`qf.analytics.vid`），1 年有效；`localStorage` 不可用时退化为本次会话一次性值（内存）。
- 用途：去重统计 UV（独立访客数），**不关联真实身份**；未登录时仅以此匿名标识聚合。
- 非 cookie 跨站追踪、不与第三方共享。

### 5.5 数据保存期限

🔴 **代码层未定义保留期限**：全仓检索 `retention / delete site_event / cleanup / TTL / expire` 均**无匹配**——既无自动过期清理，也无定时删除任务。

→ **法务待确认**：须明确 `site_event` 留存时长（如 13 个月 / 24 个月）并在隐私政策与系统实现中落地。

### 5.6 用户撤回同意后的处理方式

- **停止未来采集**：撤回后 `qf.analytics.optout='1'`，前端不再发送任何事件（代码层已验证）。✅
- 🔴 **已采集数据未做删除**：代码层**无"撤回后删除历史 site_event"逻辑**；撤回仅阻止后续上报，已落库数据保留。
→ **法务待确认**：是否满足 GDPR 第 17 条（被遗忘权）/《个人信息保护法》第 15、47 条（撤回同意后删除）；若须删除，需在后端新增按 `visitor_id` 的删除/匿名化能力。

### 5.7 隐私政策对应条款

🔴 仓库内**无隐私政策文档**（全仓检索 `privacy/隐私` 仅命中 `SiteEventController`/`WebPageController` 代码注释与测试，无政策文件）。

→ **法务待确认**：须补充/发布隐私政策，明确分析 Cookie 用途、字段、保存期限、撤回方式与联系方式，并在同意横幅提供"了解更多/隐私政策"链接。
