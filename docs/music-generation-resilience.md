# 音乐生成可靠性与降级

本次变更不包含数据库迁移，不更改现有作品、歌词或运行环境配置，也不接入新的收费音乐供应商。

## 要求编译

- 结构化偏好、补充要求、创作计划分别保留。任务保存最终描述和原始创作计划快照。
- 默认设置不能覆盖原始明确要求；用户确认的新设置在冲突处优先。
- 去除重复排除项和冗长模板；预算不足时先省略可选编曲，再把系统选项长描述换成分类标签。
- 分类标签仍保留选择顺序、曲风、乐器、人声等维度和完整自由输入。不能通过裁切字符串满足上限。
- 无法安全容纳的明确要求直接返回可编辑错误，不创建音乐任务、不调用供应商。
- 老作品仅有风格名称时，也通过供应商纯本地展开规则冻结完整描述。

`POST /api/app/works/{work}/generations/preflight` 接收 `revisionId`，返回版本、最终长度预算和整理提示。不占额，不落库，不调用模型。正式提交仍在事务内重新检查版本、编译和冻结快照，预检不作为跳过正式校验的授权。

`POST /api/app/works/{work}/music-settings/preview` 在编辑音乐设置时联合检查原始创作计划；通用目录预览接口保留兼容。

## 恢复边界

| 阶段 | 状态与处理 | 再次付费生成 |
| --- | --- | --- |
| 输入校验失败 | 留在编辑页，提示调整 | 不调用 |
| 本地准备失败 | `LOCAL_PREPARATION_FAILED`，明确未发送 | 不自动调用 |
| 连接建立失败 | `PROVIDER_CONNECT_FAILED`，明确未发送 | 不自动调用 |
| 供应商明确拒绝 | 区分参数、认证、余额、限流、接口不可用 | 不自动调用 |
| 超时、断连、5xx、响应无法解析 | `SUBMISSION_UNKNOWN`，保留原请求 | 禁止自动重发 |
| 已取得平台编号 | 查询原任务，异常按退避重试 | 不调用 |
| 查询连续异常或等待过长 | 后台核对，五分钟一次只读查询 | 不调用 |
| 音频归档失败 | 自动有限重试、刷新原音频地址；用户可仅重试保存 | 不调用 |

Worker 在发送前单独记录准备阶段。可能已经发送的请求不因内部异常被当作“未发送”。获得任务编号后的数据库写回异常只重试写回，并记录安全任务标识供排障，不重发生成。用户结束无编号等待后，如果收到已确认的迟到平台编号，可恢复同一个原任务。

确定未受理的失败释放每日占额，并幂等返还站内积分。结果未知不会自动返还；已生成音频的保存失败也不会当作未生成退款。平台真实账单与站内积分是不同概念。

## 服务冷却

当前使用进程内准入熔断：认证、余额和接口错误冷却 600 秒，限流冷却 60 秒，五分钟内累计三次提交连接或未知异常冷却 60 秒。单个用户的输入错误不熔断其他用户。

熔断只阻止新提交，不阻断已受理任务的查询、音频归档、已有歌曲试听或分享。重启会重置进程内冷却；多实例部署尚未共享熔断状态，持久化任务幂等和数据库租约仍跨实例生效。

备用供应商未配置，不能在结果未知时自动切换。后续启用备用服务必须先确认原请求未受理或已明确失败，并说明效果和费用差异。

## AI 辅助精简

音乐设置中的 AI 入口只整理用户填写的补充音乐要求，明确点击才调用现有 DeepSeek，不在任务提交事务中调用。建议先展示，用户确认后才替换编辑框，之后仍需保存设置。不能自动修改歌词、作品故事或创作计划。

- 每次最多 300 字输入和输出，供应商请求超时 15 秒，不自动重试。
- 数字、BPM 和识别出的否定限制必须保留；结构或约束校验失败保留原文。
- 自由文本的语义等价不能完全由规则证明，因此必须由用户预览确认。
- 限制每用户一个在途请求、全局并发默认两个；失败不阻断确定性的要求编译。
- 配置复用后端 DeepSeek 密钥；没有可用配置时隐藏入口。

## 页面与浏览器恢复

只有正式任务受理后才展示制作进度；普通输入问题不显示创作失败弹窗。刷新回作品时展示非阻塞进度，用户可主动展开。

浏览器按账号与作品保存原请求键和歌词版本编号，不包含歌词正文或凭据。HTTP 结果未知后刷新仍核对原请求。用户主动“恢复原请求”只重放本站相同幂等键和原歌词版本，不能生成新键绕过核对。存储不可用时保留本页状态并提示离开风险。

最近一次归档失败在页面直接显示“仅重试保存音频”，不藏在历史记录内。上一版歌曲保持可试听、下载和分享。

## 可配置项

以下均为非敏感配置，密钥仍只能位于本机忽略提交的私有配置或服务器环境中。

```properties
qingfeng.providers.kie.max-title-characters=80
qingfeng.providers.kie.max-lyrics-characters=5000
qingfeng.providers.kie.max-style-characters=1000
qingfeng.providers.kie.max-negative-characters=500
qingfeng.generation.review-after-minutes=30
qingfeng.generation.max-query-failures=6
qingfeng.music-settings.simplify.enabled=true
qingfeng.music-settings.simplify.concurrent-global=2
```

KIE 预算允许调小，不允许高于当前模型能力。查询进入核对状态后仍保留平台编号并低频查询，不把未知任务宣告失败或重复扣款。
