## 已修复的问题

- Java 17 HTTP 请求计时不足以限制已返回响应头、但不结束的响应体。规划模型和头像供应商请求增加完整响应期限、响应体大小限制及原始请求取消；创建操作不自动重试，未知头像提交保持待核实。
- 观察连接超时后若网络发送仍占用线程，不能立即归还容量。SSE 在实际读写退出后才释放名额，避免慢连接累积占满工作线程；超时回调不等待正在发送的写锁。
- 原生工具和兼容 JSON 计划采用同一服务端参数校验。未提供的可选值不清空原作品资料；无法安全解释的清空组合请求整轮澄清，不继续按旧配置收费生成。
- 每轮同一种付费动作最多一次，包括查询结果后的再次规划；歌词和音乐各执行一次的组合继续支持。请求重放保留原幂等键。
- 对指定其他作品或版本的分享、播放等操作，缺少相应目标选择时停止，不把当前作品当作指定目标。
- 头像保存与任务租约检查在同一事务中完成。过期执行者不能在另一执行者退款后写入头像；旧文件只在事务提交后删除，新文件在明确回滚后清理。
