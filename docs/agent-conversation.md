# 对话式音乐创作

Agent 页面是用户端功能的统一对话入口。通过服务端能力目录规划操作，调用原有业务服务，并把真实结果、候选列表和确认按钮呈现在对话里。歌词、音频、封面与操作绑定具体作品和版本，试听样曲始终标明为平台样曲。

## 用户功能覆盖

| 功能 | 对话操作与原有业务能力 |
| --- | --- |
| 聊天与灵感 | 自由讨论、润色灵感、精简音乐要求、能力清单 |
| 歌词 | 生成、改写、保存用户完整歌词、单句润色/押韵/口语化/缩短、歌词历史版本选择 |
| 照片写歌 | 在聊天中打开真实照片创作面板，由用户选图、查看费用后提交；完成后返回对话继续创作 |
| 音乐制作 | 生成音乐、再次生成、风格/人声/速度等设置、完整分类与配方、排除要求、预览设置、查看任务实际参数 |
| 音频 | 列表、候选选择、历史音频选择、播放、下载、导入音频、局部修改、同步歌词与时间轴 |
| 作品库 | 新建空白草稿、分页列表、按歌名搜索、按列表序号定位、切换作品、修改标题/故事/收礼人/场景/寄语、确认删除 |
| 封面 | 查看/选择封面、上传图片、基于已有图片进行AI修改、查看改图任务 |
| 分享与互动 | 创建/撤销七天分享链接、当前自有作品点赞、推荐样曲发现/试听/收藏/点赞与取消 |
| 生成任务 | 查看真实进度、按原规则取消、重试归档、确认结束结果核查 |
| 积分与邀请 | 当前余额、生成价格、改写免费次数、本人收支、使用额度、邀请链接、接受邀请 |
| 支付 | 查询开放套餐和本人订单、核对真实状态、按原规则关闭未付订单；对话内收银台沿用现有支付授权流程 |
| 账号与隐私 | 登录、账号设置/退出/恢复入口、匿名分析同意设置、经确认请求处理本人的历史分析数据 |

原生文件选择、登录验证、支付授权与恢复码展示使用对话内专用窗口。密码、验证码、支付凭证和恢复码不交给模型处理，不保存在普通聊天结果中。支付创建、续付及授权继续由原有收银台负责；查询订单不会替用户发起扣款。

自带歌词与音频可先建立草稿再保存或上传，不先调用收费生成。当前目录共65项操作（聊天另计），由注册的服务端能力自动汇总，不使用前端手写的伪功能列表。`photo_song` 只打开照片写歌面板，图片由原有上传接口处理，打开窗口不触发生成或扣费。

此目录涵盖用户端业务能力。内部运营数据看板、身份回调、支付回调、供应商回调、后台调度不是普通用户的可执行工具，既有权限不会因 Agent 而扩大。

## 理解与多步执行

- 模型接收服务端实际注册的能力目录、最近20条文字、当前作品和最近6份结构化结果；不能自创能力ID。
- 一次最多6步、最多2次模型规划。先查列表再选择时，真实查询结果可回流继续规划；序号只对应最近一次同类型列表。目标不唯一或缺少列表时询问，不猜测作品。
- “先写词再生成音乐”按依赖顺序执行，在同一作品上使用刚保存的新歌词。每次请求最多一次歌词生成及一次音乐生成，不把同一请求扩成批量收费。
- “不要分享，生成音乐”按动作分别识别否定；“只写歌词”不能被转成音乐生成。服务端再次校验原始指令，不依赖模型自报的授权。
- 删除作品、清除分析数据、结束结果核查先显示具体目标。确认绑定准备时的参数；作品版本变化后旧确认失效。删除复用业务层行锁并再次核对版本。
- “生成音乐然后分享”保存已明确授权的后续步骤。只有原作品、歌词版本和任务仍一致且任务成功时，状态接口才提供固定请求键的续做指令；浏览器发送POST执行。切换对象、新的用户消息、失败任务或重置会话均不会误续做。浏览器关闭期间不会执行，重新打开可在24小时内恢复；普通确认一小时内有效。
- 上传、登录、支付等原生操作以及封面异步任务会暂停依赖步骤；完成后可在对话中继续，不冒充已自动执行。
- 一轮最多触发一次播放或下载，后续只读查询不会覆盖这个动作；若当前音频已被另一页面切换，旧请求重放不会播放或下载另一首。需要多次播放、下载或随后切换作品时分轮执行。

常用示例：“查看所有功能”“找出我的毕业歌”“打开第二首，改成女声再生成”“切回上一版歌词”“生成完成后分享这首歌”“打开照片写歌”“查看我的积分明细”“打开充值窗口”。

## 接口与执行

- `GET /api/app/agent/conversations/current`：当前用户的会话。
- `POST /api/app/agent/conversations/{id}/messages`：`text`、UUID `requestKey`、可选 `locale`。
- `GET /api/app/agent/conversations/{id}/state`：刷新或恢复当前会话与音乐任务。
- 消息提交与状态查询均返回 `messages`、`songCard`、`taskId`、`action`、`shareUrl`、`liked`，以及可空的 `continuation:{requestKey,text}`。续做文本固定为“继续已安排的操作”，必须使用服务端的原请求键。
- 助手消息的 `contentJson` 可包含 `kind`、`items:[{id,title,subtitle,data}]`、`commands:[{label,text,kind}]`。命令种类和媒体路径经过前端白名单检查；模型任意URL不会成为可执行按钮。
- `songCard.audioOrigin` 来自真实音频来源，导入音频不标记为AI生成。卡片音频、歌词和当前封面均使用实际资源指针。
- 音乐提交复用现有预算预留、任务持久化与生成工作器。页面每三秒查询在途任务，不在浏览器直接调用模型或音乐供应商。
- 普通聊天由模型根据最近二十条文字、当前作品与音乐参数回答。执行前另行校验原始用户指令；否定、知识问答、引用里的命令不会直接执行付费生成或分享。
- 新作品与当前作品再生成分开处理；歌词改写携带基础歌词版本。音乐参数先写入真实音乐设置，再冻结到任务。
- 明确请求才执行分享；分享使用现有七天有效、可撤销的链接。点赞仅开放当前用户拥有的作品，使用 `work:` 键空间，与公开运营样曲隔离。

## 请求重试与重置

浏览器保存未确认消息的原请求键。超时后重试同一个键，不另造付费请求。后端使用现有 V32 会话消息表保存执行记录，不保存递归嵌套的完整会话快照。

模型或工具执行中的消息不自动重执行。近期执行中的请求会阻止另一标签页重置会话；超过十分钟仍未恢复时，用户可显式重置。重置保留隐藏的请求记录，避免旧请求重试后重复执行。重置聊天不会取消已提交音乐任务，作品仍保存在作品库。

音乐任务忙时明确告知稍后重试，不自动排队新收费任务。已提交供应商的任务按现有取消规则处理，不保证可撤销。

## 配置与运行边界

此改动不执行数据库迁移、不修改私有配置、不发布或重启任何服务。已有 V32 会话表是启用前提，不要对日常主库自动运行未上线迁移。

经授权发布并核对数据库版本后，由部署环境提供：

```properties
qingfeng.agent.chat.enabled=true
qingfeng.agent.intent.llm-enabled=true
```

模型连接复用服务端现有 DeepSeek 配置；密钥只放私有配置或环境变量。歌词和音乐生成继续使用既有功能开关及供应商配置。两个 Agent 开关默认关闭，关闭时页面显示服务不可用，不退回虚假的创作流程。本地日常入口仍遵守 `scripts/start-main.ps1` 的线上匹配版本约束。

## 验收

1. “你好”“你是什么模型”：正常回复，无作品或生成任务写入。
2. “先写歌词，不生成音乐”：仅生成歌词；“副歌改得更有力量，其他不变”基于现有版本修改。
3. “改成女声，90 BPM，其他不变”：保留语言与配器，真实生成设置生效。
4. “用当前歌词生成音乐”：真实任务进入队列；同一请求重复提交仍只有一个任务；刷新恢复状态。
5. 任务完成后，卡片歌词版本与音频一致，播放和下载同一音频。
6. 分享、撤销、点赞与取消点赞操作当前作品；其他用户不能读取或操作该私人会话。
7. 切换账号不会展示上一个账号的对话或继续发送其未确认消息；中文输入法选词不会误发送。

自动化验证使用 H2 内存数据库、受控模型响应和本机 HTTP 模型适配测试，不连接主库、不调用付费生成。真实供应商音质与生产启用效果需要在后续获授权发布时验收。

## 后续能力

社区公开发布、外部平台发行、音频无缝延长尚未接入，系统明确说明。作品按名称搜索目前限最近2000首，列表每页20首；更早作品可分页查找或按真实ID打开。封面AI修改需要已有来源图片，不能声称提供从零文生图。完整歌词保存、单句建议和风格参数更新均沿用原业务校验，供应商是否可用仍由当前环境配置决定。

本次仍只完成开发与本地合并，不改变线上或日常入口运行版本、不打开模型开关、不执行生产迁移、不触发真实支付或收费生成。
