# 深圳主库与新加坡读副本验证

三个脚本分别验证真实数据库、隔离故障和浏览器性能。它们不切换 DNS、不修改 Nginx 线上配置，也不创建生产测试数据。输出为 JSON，可保留在忽略提交的本地目录。

## 1. 真实数据库

从能够执行两台机器管理命令的工作站运行。每个参数是 JSON 格式的命令及参数数组。该命令须能从标准输入接收短 shell 程序，并通过已经配置好的 SSH 主机密钥检查或云管理入口运行。

```powershell
$sz = '["python",".cache/shenzhen-deploy/remote.py","new"]'
$sg = '["python",".cache/shenzhen-deploy/remote.py","old"]'
python scripts/regional_db_check.py --primary $sz --replica $sg
```

也可使用已经配置并校验主机密钥的 SSH 别名，例如 `["ssh","-T","qf-shenzhen-admin"]`。凭据只从各服务器的既有 MySQL 客户端配置读取。脚本校验实例身份，等待文件与位置复制屏障，再对比近期不可变账本行的摘要。较新的写入无需在脚本运行期间暂停。输出包含样本数量，原始行和摘要不打印。该样本可检出缺行或内容不一致，不能替代全库核验。

默认 6 个读取连接各执行 10 次小查询，检查查询 p95、复制线程、复制错误及延迟。写约束检查在副本实例通过身份校验后才执行，UPDATE 谓词恒为假，分别验证应用账号权限和副本管理员的只读限制。诊断失败时进程退出非零。

## 2. 隔离故障演练

在安装 Nginx 和 Python 3 的 Linux 环境运行。脚本创建临时 Nginx 进程、两个模拟上游和三个回环端口，退出时回收资源。无需使用真实域名、应用、数据库或系统服务。

```bash
python3 scripts/regional_failover_check.py
```

`current_shape` 模拟现有静态回退形状与动态请求直达深圳的规则。`proposed_bounded` 验证候选回退限并发和超时。两套规则都测健康请求、应用端口关闭、模拟数据库故障、跨境响应抖动、两端同时异常的突发请求，以及本地恢复。模拟数据库故障的本地读取使用 `/shadow/db-read`，对应未来候选读路由。

关注 `primary_calls`、`primary_peak_in_flight`、状态码和最长耗时。当前规则缺少回退并发上限时，全部测试请求可以同时到达主站；候选规则通过有限拒绝和超时控制主站并发。本报告只覆盖隔离网关与模拟故障，不能当作生产主站无雪崩的保证。候选限值仅用于演练。

## 3. 伦敦真实分享页基线

应在可信的伦敦主机和专用测试浏览器上运行。脚本要求出口通过 GB/LHR 自检。该检查是出口验证，仍需确认执行主机位于伦敦。分享链接放入权限受限的私有文件，或通过环境变量 `QF_SHARE_URL` 提供。脚本只输出匿名时间指标和公开 IP，不输出链接、歌词、响应正文或签名 URL。不要启用 Playwright 网络调试日志或把分享链接提交到公共可查询的探测服务。

```bash
python -m pip install playwright
python -m playwright install chromium
python scripts/regional_london_check.py --share-file /private/share-url.txt --pairs 5
python scripts/regional_london_check.py --share-file /private/share-url.txt --pairs 5 --target-ip 47.84.5.172
```

第一条测当前 DNS 路由。第二条只在测试浏览器进程中把主站域名指到新加坡，保留 HTTPS 主机名、证书校验和媒体域名的正常解析。同时可用 `--target-ip 120.77.19.199` 对照深圳入口。对照运行应使用同一条链接、同样的轮次与同一伦敦主机。

`current_split` 走正式页面及正式歌曲信息接口，记录 HTML 首字节、卡片显示和点播放到 playing 的时间。`combined_replay` 用同页真实元数据在浏览器内即时回放，估算少一次跨境请求的收益。它不计入未来内联数据在 HTML 中的传输成本，也不会验证候选服务端实现。每次测量创建新浏览器上下文，第一组顺序在后续配对中交替。浏览器层禁用请求缓存，CDN 缓存冷热仍取决于实际流量，报告会附带可见的音频缓存标记。默认只对正式路径测播放。`--allow-non-london` 与 `--skip-playback` 可用于本地冒烟，不能作为伦敦完整基线。

默认测试匿名访问。若播放被邀请码弹窗挡住，输出会记录 `invite-gate-overlay` 并返回非零，同时保留首屏数据。可使用 `QF_INVITE_COOKIE` 私下传入既有访问 Cookie，另跑一组已获准访问的对照。脚本会标记这组结果，且不会输出 Cookie。匿名与已获准访问的结果应独立比较。测试浏览器关闭分析采集，并拦截非读取请求。

## 4. 对比真实合并响应

使用同一伦敦执行机、同一条有效分享链接和相同配对数。两个候选入口均需持有 `cheerfulmusic.com` 有效 TLS 证书，保留主机名并让浏览器单独固定目标 IP。分开运行以下两组，将占位符替换为各自验收入口的 IPv4 地址。

```bash
python scripts/regional_london_check.py --share-file /private/share-url.txt --mode live-split --pairs 5 --target-ip "$SPLIT_IP"
python scripts/regional_london_check.py --share-file /private/share-url.txt --mode live-inline --pairs 5 --target-ip "$INLINE_IP"
```

实际合并模式校验 `Server-Timing` 的 `gift_data=inline` 标记（响应头用 `gift_data;desc="inline"` 表示）和歌曲信息请求次数为零。此模式会计入真实首屏数据的传输、解析、页面渲染与点击播放，报告按组记录实际源站 IP。先做匿名完整播放，再按需要以已有邀请码会话进行对照。未部署合并版本时仍可用 `compare-replay` 输出估算，保留实际结果与回放结果的区别。

## 5. 无伦敦测试机时模拟首屏

先用伦敦公共探针测量公开静态页的连接延迟。使用探针给出的往返延迟中位数设置浏览器的额外延迟。只给可信浏览器提供真实分享链接。

```bash
python scripts/regional_london_check.py --share-file /private/share-url.txt \
  --mode simulate-london --latency-ms 250 --pairs 5 --skip-playback
```

脚本在同一浏览器内获取一次已部署的合并响应，再交替测量两种模式。分步模式从同一份 HTML 移除内联歌曲信息，触发一次真实的歌曲信息 GET。合并模式直接读取 HTML 中的歌曲信息。测量范围从 HTML 回放到歌曲卡片可见，两组的静态资源仍走实际网络。额外延迟为模型输入，未包含真实伦敦主文档首字节、DNS、握手和英国媒体缓存表现。报告标记为 `simulated_london_browser`，可用于比较请求链路，不用于伦敦正式流量验收。

## 6. 新加坡静态回退与观察项

三个 Nginx 片段位于 `Qingfeng_AI_Music/deploy/nginx/`。`sg-fallback-http.conf` 只加载一次，作用域为 `http`。将 `sg-fallback-budget.conf` 放到 `/etc/nginx/qingfeng/`，由命名回退位置引用。`sg-static-read-server.conf` 替换新加坡主站 HTTPS 虚拟主机内现有的静态读取位置及旧命名回退位置。保留动态请求的现有路由。变更前备份原配置，先验证试点，再用 `nginx -t` 检查整份配置并 reload；回滚时恢复备份，重新检查并 reload。

限值从已有隔离实验的 4 个回退并发起步。区域侧超时、异常和静态资源缺失可回退一次，普通 `403` 直接返回。超额返回 `503`，超时返回 `504`，两者带 `Retry-After: 1`。Nginx `proxy_read_timeout` 约束两次上游读取之间的空闲时间。发布验收应同时观察回退量、快速拒绝率、回退耗时和深圳健康。日志 `/var/log/nginx/qingfeng-sg-static-fallback.log` 记录状态与耗时，不记录路径、令牌、IP 或 Cookie。隔离脚本直接读取版本库中的限流和超时片段验证行为。

分享页面通过现有分析同意机制发送 `gift_card_ready` 和 `gift_play_result`。首屏事件按 `inline`、`fetch` 分组，耗时从当前分享组件开始处理计起。播放事件按 `playing`、`error` 分组，耗时从点击播放计起。两个事件都可按聚合国家查看样本量、p50、p95 和播放失败率。禁止在这两个事件中写入 token、歌词、标题、URL、身份和访客会话标识。服务端采集总开关和用户同意仍生效，伦敦合成测试关闭分析采集。
