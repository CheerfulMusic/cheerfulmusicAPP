# 账号页浅色修复与本地 Google 配置

2026-11-05，本轮未部署、未重启或修改线上服务。

- 原因一：同事账号页与账号菜单仍含深色卡片的固定颜色，全站浅色主题将标题变成深色，导致深色背景上的标题几乎不可见。已将 Google 登录、已登录资料、找回码卡片、操作栏及账号菜单改用共享浅色变量。
- 原因二：本机运行的后端 Google 状态为 enabled=false，原模板会直接隐藏整个登录卡片。现在卡片保留，未启用时禁用登录按钮并给出明确提示，找回码方式继续可用。
- 保留真实 Google 登录、切换账号、退出设备及找回码接口，未替换为占位功能。

用户要求连接服务器查询配置后，通过 SSH 只读取得线上已有 Google OAuth 配置，并将所需配置写入被 Git 忽略的 `Qingfeng_AI_Music/config/local.properties`。原本地文件已备份在被忽略的 `.backups/` 下。没有输出或提交 Client Secret，也未读取或覆盖其他服务器配置。

本机启用开关已设置为 true，回调为 `http://127.0.0.1:5173/api/public/auth/google/callback`，通过 Vite API 代理回到本地后端。线上 HTTPS 回调保持原样。本地 Google 控制台授权重定向地址是否已登记尚未核实；直接访问 Google 授权页的网络验证未完成。需要重启 IDEA 后端加载配置，真实 Google 授权完成状态不能仅凭配置复制认定。

验证：96 项前端测试、类型检查及生产构建通过；57 项离线浏览器检查覆盖启用、未启用、已登录三种状态，1440/390/360 宽度、中英文、浅色卡片、响应式布局、账号菜单以及显式点击仍请求 `/api/public/auth/google/start`。测试没有登录实际 Google 账号。
