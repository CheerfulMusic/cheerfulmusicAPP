# 歌曲分享访问修复（2026-11-06）

状态：本地及独立整合源码已完成。用户明确要求先保留本地，暂不部署；线上服务、配置和真实分享记录未改动。

## 原因与行为

用户提供的 `/works/a3427a06-03ea-42e7-8dea-46b92d53bb45` 是私人编辑页。线上只读确认作品仍存在，存在1条有效分享记录；原始分享令牌只保存哈希，不能从数据库恢复成链接。没有把私人编辑地址改成公开地址，也未创建或撤销真实用户的分享。

此前“分享歌曲”只是滚到页面下方，用户还需点“创建音乐礼物链接”。此外前后端邀请码门禁拦截了公开收听页和音频。

修复后：

- 点击“分享歌曲”直接打开弹窗，创建 `/gift/<43位令牌>` 链接，突出复制和预览，提示不要分享编辑地址。
- 同一弹窗、同一歌曲版本关闭再打开复用有效链接；请求失败只提供主动重试。歌曲、歌词或封面上下文变化时丢弃旧响应。
- 公开收听页无需登录/邀请码；不请求账户接口或创建作者会话。进入首页/创作仍须通过邀请码。
- 后端只放行带格式正确令牌的分享快照、音频、封面 GET/HEAD；私人作品、私有音频、写接口仍受保护。分享有效性仍由服务端检查。
- 令牌失效/撤销/过期不能继续获取快照、音频、封面；保留原有7天有效期和作者撤销入口。
- 原有链接若为 `/works/...` 仍是私人页。上线后需作者点击分享并重新发送复制出的公开收听链接。
