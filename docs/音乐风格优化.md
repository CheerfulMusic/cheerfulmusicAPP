# 音乐风格优化

2026-11-03，本地代码已实现；未部署，未调用付费生成接口。

## 生成行为

- 24 个完整匹配的站内预设，在 KIE 适配层展开为具体编曲描述，包括主奏乐器、节奏、速度范围、演唱方式和编曲层次。原始风格仍按作品版本保存在生成任务里。
- 例如“温暖民谣”展开为木吉他指弹、少量钢琴、轻刷打击乐、舒缓节奏、自然亲密的演唱与简洁编曲。“轻快说唱”明确包含说唱主歌和旋律副歌；国风包含古筝、琵琶、二胡、笛子和五声音阶。
- 自定义输入不会匹配子串或被替换成某个预设。例如“温暖民谣，但不用吉他；用钢琴，95 BPM”原样保留。输入应尽量写清乐器、节奏和情绪；继续限制为80字。
- 男声/女声除了独立的 `vocal_gender=m/f`，还在风格描述中追加相同的人声偏好；自动选择不强加性别。歌词原样发送，不在音乐接口中重写歌词。
- 当前仍为有人声歌曲，钢琴、轻音乐、电影配乐等选项指歌曲编曲。页面已明确说明，不会切换为纯音乐或省略已确认歌词。

## 初始参数与边界

按[KIE 自定义模式文档](https://docs.kie.ai/suno-api/generate-music)，可在后端私有配置中覆盖：

```properties
qingfeng.providers.kie.style-weight=0.85
qingfeng.providers.kie.weirdness-constraint=0.25
qingfeng.providers.kie.variety=0
```

`style-weight` 和 `weirdness-constraint` 范围0~1，保留两位小数；`variety` 为整数0~4。越界配置会启动失败，不静默截断。初始值目的是增强风格方向、减少创意偏移与风格变化，尚未用真实付费对照试听验证，不承诺100%符合风格或人声性别。

展开后风格仍受1000字符限制，在预校验和发送前校验；超长输入不截断、不调用供应商。保留原有一次提交、查询重试、幂等和额度控制。

## 已生成歌曲与后续修改

- 结果页按当前试听音频的 `assetId` 匹配原始生成任务，展示那次任务的风格与人声偏好，不用当前草稿或最近一次任务替代。
- 导入音频显示“导入音频”；缺失历史任务信息时明确显示记录不可用，不猜测风格。
- 音乐生成区域显示下次生成所用的当前风格与声音。修改设置不会改变已有音频，需要用户主动提交新的生成任务。
- 本次没有改变数据库结构或已有歌曲，也不会自动重新生成或扣除额度。

供应商请求通过本机 HTTP 模拟服务验证，覆盖24种风格、歌词不变、男女声一致、自定义文本保留、参数范围与无效输入零网络请求。前端验证按音频匹配历史任务，不将新草稿设置误标到旧音频。
