The rhyme checker reads these pronunciation data files at runtime.

cmudict.dict.gz
  CMU Pronouncing Dictionary, https://github.com/cmusphinx/cmudict
  Data file cmudict/data/cmudict.dict from the cmudict 1.1.3 distribution.
  https://pypi.org/project/cmudict/1.1.3/
  Wheel SHA-256 e4d421341bf9fa774bcded8e7d6c5d73a1bf8f88edbe129207713850abac4995
  The data license is in cmudict-LICENSE.txt. No wrapper code is included.

mandarin.tsv.gz
  Character and contextual phrase data from pypinyin 0.55.0.
  https://pypi.org/project/pypinyin/0.55.0/
  Wheel SHA-256 d53b1e8ad2cdb815fb2cb604ed3123372f5a28c6f447571244aca36fc62a286f
  The TSV is sorted by character or phrase, with comma-separated pronunciations.
  Character entries retain all readings. Phrase entries retain the final character's readings.
  Data upstreams https://github.com/mozillazg/pinyin-data and
  https://github.com/mozillazg/phrase-pinyin-data. License notices are alongside this file.
