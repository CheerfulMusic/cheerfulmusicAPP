# generation

音乐生成任务、状态转换与恢复。

已实现任务快照、幂等、数据库扫描、供应商及任务租约/心跳、单个在途生成、提交前落库、查询恢复、未知提交待核对、归档重试及到期地址只读刷新。归档按任务唯一登记，不重复付费生成。已接入KIE Suno，模型不可用时返回503而不入队。运行时业务通过WorkApi/LyricsApi和归档/下载端口交互；仓储、HTTP下载与文件适配在infrastructure。

新任务由后端等待5秒后才可提交。QUEUED状态可原子撤销为CANCELLED并释放站内歌曲额度；开始提交后不承诺取消或退款，未知提交不会自动重发。任务快照包含原始风格、人声偏好和歌词版本。
