# 模型创作额度

`UsageBudget` 是付费创作的准入端口，区分歌词、歌曲、时间轴与AI封面。基础设施实现通过数据库锁和预留记录同时执行个人/全站每日次数及在途数量检查。

歌曲用例在创建任务的同一事务中预留；歌词适配器在登记请求的短事务中预留，结束事务后才调用模型。查询、归档、手动歌词保存不占额度。重复请求复用记录，结果未知时保留额度和并发位置，不自动重发付费请求。

访客身份不是实名账号；全站上限用于控制访客清除 Cookie 后的总体消耗。此模块不提供余额充值、计费结算或供应商真实余额。

音乐每日默认个人20次、全站20次；AI封面为独立额度，默认个人5次、全站20次。封面上传、裁剪和应用不调用模型。音乐提交前撤销与准入使用同一锁序，在状态确认尚未提交时才释放预留；失败和结果未知不会自动退款。
