# 品牌 Logo

按用户提供的品牌规范图整理：品牌红 `#F93822`，字标黑 `#222223`。

- `logo-symbol.svg`：独立品牌图形，沿用项目既有轮廓，收紧透明留白。
- `logo-mark.svg`：适用于网站图标的红底反白版本。
- `wordmark-zh.svg`：中文“青风音乐”，使用 OPPO Sans 3.0 Bold 排版后转为矢量路径。
- `wordmark-en.svg`：上下两行“CHEERFUL / MUSIC”，使用 Krona One 排版后转为矢量路径。

字标不依赖用户电脑安装字体，不下载整套字体库。这里只保存排版后的四个汉字和英文名称的图形，不分发字体文件。当前组合依据参考图制作，不作为官方原始 Logo 文件的逐点复刻。

字体来源与授权说明：

- OPPO 官方下载与使用说明：https://www.coloros.com/article/A00000050/
- Krona One 官方字体：https://github.com/google/fonts/tree/main/ofl/kronaone
- Krona One SIL OFL 1.1：https://raw.githubusercontent.com/google/fonts/main/ofl/kronaone/OFL.txt

当前产品统一展示英文组合，不随界面语言切换；中文矢量素材保留备用。共享 `BrandLogo.vue` 用于网页、App 和页脚。
