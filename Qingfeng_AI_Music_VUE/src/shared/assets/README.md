## 国际分享图标

`public/brand/share-channels` 的平台素材随应用本地分发。平台标识仅用于标明分享目的地，版权与商标归各自权利人所有。

- WeChat 使用微信手机客户端图标。[微信设计品牌工具](https://wechat.design/tool/brand/)
- YouTube 使用品牌资源中心的数字红色原版图标。[YouTube 品牌资源](https://brand.youtube/youtube-icon/)
- WhatsApp 使用品牌包的白色图形和官方绿色底色。[WhatsApp 品牌资源](https://about.meta.com/brand/resources/whatsapp/whatsapp-brand/)
- Instagram 使用官网提供的 180 像素触屏图标。[Instagram 官网图标](https://static.cdninstagram.com/rsrc.php/yw/r/icwX0xAk0pz.webp)
- Facebook 使用品牌包的主标识。[Facebook 品牌资源](https://about.meta.com/brand/resources/facebook/logo/)
- Telegram 使用官方媒体包的原始 SVG。[Telegram 媒体资源](https://telegram.org/press)
- X 使用官方白色图形和黑色底色。[X 品牌工具](https://about.x.com/en/who-we-are/brand-toolkit)
- Email 使用通用信封图标。
