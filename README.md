# 青风音乐

面向电脑与手机网页的音乐礼物创作项目，采用Cheerful Music品牌主题，支持中英双语。当前实现：故事草稿、DeepSeek歌词编写与版本确认、KIE Suno歌曲生成适配、音频上传/试听/下载、作品管理、7天礼物分享与撤销、Google登录与当前设备登录管理、一次性作品找回。模型和Google登录能力由后端私有配置开启。现状、验证范围和发布依据统一见[当前状态](docs/当前状态.md)。阶段验收文档保留当时记录。

## 本地体验

日常运行已按用户要求统一使用 **cheerfulmusic.com 线上生产主库**，不再启用独立登录/支付测试数据库。正常操作会影响同一套线上数据。环境需要 Java 17、Node、PowerShell 7 与本机已配置的 SSH 访问，不要求启动 Docker 测试库。

```powershell
./scripts/start-main.ps1
./scripts/stop-main.ps1
```

打开 `http://127.0.0.1:5173`。启动入口固定主库隧道与 8080/5173，认证服务使用线上同版 JAR；业务与媒体接口复用线上后端。私有连接与版本清单位于 `.secrets`，不提交 Git。原工作区未提交修改保留，主库入口的前端目录须与已上线版本匹配。

本地不执行数据库迁移或生产后台任务，不把模拟支付与测试夹具写入主库。后端改动按项目上线流程验证、备份、发布后，再同步本地运行版本。具体位置、边界及旧库保留情况见[主库日常运行](docs/主库日常运行.md)。线上部署见[阿里云部署](docs/阿里云部署.md)。

## 账号与登录

网页右上角常驻账号入口：未连接时显示“登录 / 账号”，已连接时点击头像展开菜单。选择“账号与登录”进入`/account`，可查看关联账号、切换Google账号、退出当前设备或使用作品找回码；手机顶栏和展开的导航同样提供入口。

退出只撤销当前设备令牌，不删除Google绑定、作品、找回码或其他设备会话。首次Google关联保留当前匿名作品，不按邮箱自动合并收藏。切换Google账号会先退出本设备，再打开Google账号选择页。

Google登录默认关闭。启用时在服务端私有配置设置`qingfeng.auth.google.enabled/client-id/client-secret/redirect-uri`，生产回调固定为`https://cheerfulmusic.com/api/public/auth/google/callback`。密钥不得放到前端、提交到Git或写入公开日志。当前线上Google应用使用外部测试模式，是否正式向所有Google账号开放以Google Auth Platform配置为准。

## 代码位置

- `Qingfeng_AI_Music`：Java模块化单体，common/business/infrastructure/server。
- `Qingfeng_AI_Music_VUE`：Vue3、TypeScript、Pinia、Router，响应式Web/H5。
- `scripts`：统一构建、启停、备份、独立恢复、存储维护。
- `docs`：架构、实施计划、配置与各阶段验收证据。
- `ui-prototype`：保留已确认的设计原型。

开始操作前可阅读[本地交付与维护](docs/本地交付与维护.md)。当前完成范围与限制见[当前状态](docs/当前状态.md)；[第三阶段验收](docs/第三阶段验收.md)为历史快照。

首次创作已调整为「写故事 → 修改歌词 → 生成与试听 → 制作音乐礼物 → 分享」，增加故事/歌词自动保存、本机恢复、歌曲结果试听、作品真实状态与模型创作额度控制。当前测试期各类每日次数不限，额度、并发数统一在 `Qingfeng_AI_Music/config/usage-limits.properties` 配置；线上使用 `/etc/qingfeng-music/usage-limits.properties`，修改并重启即可。详见[统一创作额度配置](docs/统一创作额度配置.md)。

作品试听支持[同步歌词](docs/同步歌词.md)：使用真实时间轴逐句高亮、滚动及点击跳转，已获取的结果长期缓存；没有时间轴时保留普通歌词展示。

「选择旋律」可指定自动、男声或女声，选择会自动保存并作为不可变的生成任务参数传给 KIE Suno。详见[声音选择与每日额度](docs/声音选择与每日额度.md)。

24种预设风格已补充具体编曲描述和风格遵循参数；结果页按试听音频展示当时的风格，保留自定义输入。实现与验证边界见[音乐风格优化](docs/音乐风格优化.md)。

创作流程现为「写故事 → 修改歌词 → 生成与试听 → 制作音乐礼物 → 分享」，支持返回修改、调整后重新谱曲、中英混合歌词、提交前撤销及DIY封面。KIE图片编辑已接入并通过离线模拟测试，未发起真实付费加工。详见[创作流程与DIY封面](docs/创作流程与DIY封面.md)。

歌词创作增加真实细节、情绪递进与副歌意象要求，支持点选润色方向；旧歌词不会自动改变。详见[歌词表达优化](docs/歌词表达优化.md)。

歌曲试听页与收礼页采用浏览器原生分段起播，不等待整首下载完成；播放器复用最近两首的原生缓冲实例。整首预加载已改为历史方案，见[完整歌曲预加载](docs/完整歌曲预加载.md)。

歌词失败请求支持释放并发、超时恢复及结果找回，用户明确重试时使用新请求标识，保留历史和已用额度。线上修复及验证见[歌词请求异常恢复](docs/歌词请求异常恢复.md)。

本地新增[局部改词与版本对比](docs/局部改词与版本对比.md)：选择歌词及重新演唱范围、生成修改版、片段循环试听与原版对比，明确选用后才切换当前歌曲，旧礼物保持原版。本轮未部署、未进行真实付费局部重唱验收。

本地创作页改为[一屏一问的故事向导](docs/一屏一问的故事向导.md)：四屏填写故事，再选择歌词语言；旋律与声音设置移至歌词页。兼容旧草稿进度，保留自动保存和浏览器返回恢复。本轮未部署。

本地修复[KIE音乐结果解析兼容](docs/KIE音乐结果解析兼容.md)：兼容统一任务的 `resultObject.lyricsData` 成品返回，避免供应商已完成而本站持续查询重试；受影响本地任务已恢复归档，没有重复生成。本轮未部署，IDEA后端重启后用于后续任务。

歌曲归档与歌词时间轴现共用KIE结果及音频版本解析；经单独授权，本次本地歌曲已取得并缓存26行真实时间轴，仅调用一次时间轴接口，未重新生成歌曲，未部署。

本地新增[音乐配方与分类偏好](docs/音乐配方与分类偏好.md)：五种可编辑配方、分类标签、排除项、自由输入和生成摘要，完整偏好随每次歌曲生成冻结。手机全屏选择、电脑分栏面板；V13需本地后端重启迁移。本轮未部署、未发起真实付费生成。
