# 首页设计方向（已由下方 v3 方案替代）

任务：突出青风品牌、专辑封面和可用试听入口，承接故事定制歌曲流程。

色彩：瓷白 #F1F4F1、青绿 #174E45、浅苔 #CBDAC7、海蓝 #A6C6D4、淡紫 #C9BEDC、日光黄 #E6D9A5。
字体：中文用微软雅黑 / 苹方的中等和粗体字重，英文用 Segoe UI。标题、说明和按钮建立尺寸层级，不使用衬线标题与装饰性全大写标签。

电脑：左对齐的短标题和创作入口，与右侧大幅专辑及唱片侧影并列；试听区三个正方形封面并排。底部播放器承接播放操作。

```text
品牌             发现 / 试听 / 制作          创作
故事标题 + 创作入口        主打专辑大封面 + 切换
                      曲名 / 播放
精选试听                         场景筛选
封面 / 曲名 / 播放    封面 / 曲名 / 播放    封面 / 曲名 / 播放
按对象进入创作                     制作流程
底部试听播放器（用户播放后出现）
```

手机：标题后立即呈现可切换的大封面，播放按钮位于封面外且始终可见；精选专辑为可横向滚动的唱片架；播放器缩为封面、曲名、播放和关闭。

自审：上一版的奶油色、衬线标题、全大写眉题、统一卡片和装饰星号容易弱化音乐内容。本版移除这些处理，将表现力集中在三个不同构图的原创矢量封面及专辑切换。品牌从风形标识、青绿、封面厂牌署名和声音体验中保持一致。

所有品牌图形为提案。试听为程序合成的原创器乐界面样曲，不宣称公司已发布作品，也不冒充 AI 生成人声。

用户明确取消必须使用青色的限制，参考 Serenata 的温暖、情感导向和成果预览。

- 淡杏 #EEE5DA：分区。

标题为中文宋体（Songti SC / STZhongsong / SimSun），正文为微软雅黑 / 苹方。桌面标题左对齐，手机主标题居中。封面使用内置 ImageGen 生成的原创 AI 场景图，不冒充真实用户或公司客户案例。

页面顺序：情感主张与可试听礼物卡 → 三个核心体验 → 送歌对象 → 三张人物作品封面与试听 → 制作流程 → 深色音乐礼物页展示 → FAQ → 创作入口。

自审：暖白与宋体是本次指定的参考方向，保留；取消上一版青绿、插画唱片、装饰光斑与重复全大写标签，将视觉重点集中在照片音乐卡。无需照搬参考网站的评价、使用人数、免费或时长承诺。同步修改创作与礼物页的配色，避免跳转后的视觉断裂。
