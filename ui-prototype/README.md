# 青风寄语 · 音乐礼物 UI 原型

当前版本：暖象牙白、酒红和香槟金，中文宋体标题与原创 AI 场景照片。参考 Serenata 的情感表达和礼物成果预览，重新设计青风音乐首页；创作页与礼物页同步品牌配色。

## 查看

用浏览器打开 `index.html`，无需安装依赖。也可以启动本地服务：

```powershell
cd E:\qingfeng_AI_music\ui-prototype
python -m http.server 4173 --bind 127.0.0.1
```

访问 http://127.0.0.1:4173 。

- 首页：`/#home`
- 创作流程：`/#create`
- 音乐礼物页：`/#gift`

首页包括个性化音乐卡、送歌对象、作品试听、三步流程、深色礼物展示、FAQ 和创作入口。支持桌面 / 平板 / 手机，手机作品列表可横向滑动。

## 交互与边界

首页可切换爱人 / 家人 / 朋友封面、筛选作品、真实播放三段本地器乐样曲，支持暂停、切歌、关闭；电脑播放器支持拖动进度。只有用户点击才播放，不自动发声。

创作支持填写故事、选择风格、编辑示例歌词、展示等待状态和礼物页。没有模型请求或付费调用，尚未接入真实歌曲生成与线上分享。表单仅保存在当前页面内存，刷新后重置。

人物照片由内置 ImageGen 生成，不是真实客户照片。完整提示词和保存文件名见 `assets/image-prompts.md`。试听为脚本 `scripts/make-preview-audio.py` 合成的原创器乐界面样曲，不是 AI 生成人声或公司已发布作品。

## 文件

- `homepage-content.js`：首页结构、作品数据与封面。
- `homepage.js`：试听播放器、封面切换与筛选。
- `homepage-premium.css`：当前品牌与响应式样式。
- `app.js` / `styles.css`：创作流程与礼物页。
- `assets/`：本地照片与音频，不依赖第三方图片地址。
- `DESIGN.md`：设计说明。

前一轮 `homepage.css` 作为历史设计保留，当前页面不再加载。
